# Security Policy

## Reporting Security or Privacy Concerns

If you identify a security, privacy, or data-handling concern involving Agent O,
contact the designated Agent O owner or your organization's approved support
channel.

Do not submit confidential information, credentials, access tokens, customer
data, or production diagnostic logs through public GitHub Issues.

## Sensitive Data

Never include the following in a public issue or repository contribution:

- Passwords or credentials
- Authentication or refresh tokens
- Session cookies
- API keys or private keys
- Unredacted message headers containing sensitive information
- Customer or tenant confidential information
- Unnecessary personally identifiable information (PII)
- Production logs containing sensitive organizational data

Use your organization's approved secure support process for cases requiring
sensitive diagnostic information.

## AI-Generated Recommendations

Agent O provides AI-assisted technical guidance. Commands and configuration
changes should be reviewed and validated before being applied to production
systems.
