# Privacy Statement for Agent O

**Effective date:** October 1, 2026
**Last updated:** October 1, 2026

## 1. Overview

Agent O is an AI-based diagnostic agent designed to assist with troubleshooting
Microsoft Outlook, Exchange Online, Hybrid Exchange, mail flow, authentication,
connectivity, mailbox, calendar, delegation, and related Microsoft messaging
issues.

Agent O operates within the Microsoft 365 Copilot environment and is intended
for authorized organizational use.

## 2. Information You Provide

To perform diagnostics, Agent O may process information that users voluntarily
provide during a conversation, including:

- Technical issue descriptions
- Error messages and status codes
- Diagnostic and log excerpts
- Non-secret portions of email headers
- Message trace or PowerShell output
- Client, operating system, and build information
- Diagnostic, correlation, or request identifiers
- Other technical information necessary to investigate an issue

Users should provide only the minimum information necessary for troubleshooting.

## 3. Sensitive Information

Do not provide Agent O with:

- Passwords
- Authentication or refresh tokens
- Session cookies
- API keys
- Private keys or other credentials
- Unredacted personally identifiable information unless strictly required
  and permitted by organizational policy
- Confidential information unrelated to the troubleshooting case

Users should redact unnecessary names, email addresses, identifiers, and other
personal or confidential information from diagnostic data whenever possible.

## 4. How Information Is Used

Information supplied to Agent O is used to:

- Understand and classify technical issues
- Identify relevant failure domains
- Analyze diagnostic evidence
- Recommend troubleshooting or remediation steps
- Validate troubleshooting outcomes
- Prepare technical escalation information when required

Agent O is designed to request only information relevant to the technical
investigation.

## 5. Microsoft 365 and Connected Services

Agent O runs using Microsoft 365 Copilot capabilities. Information processed
through Microsoft services is subject to the applicable Microsoft agreements,
privacy commitments, security controls, and the policies configured by the
organization operating the Microsoft 365 tenant.

If Agent O is configured with additional knowledge sources, connectors, or
services, information may also be processed according to the policies
applicable to those services.

## 6. Data Access and Permissions

Agent O does not grant users additional permissions to organizational data.
Access to Microsoft 365 information and connected resources remains subject to
the user's identity, permissions, organizational policies, and applicable
Microsoft 365 controls.

## 7. Data Retention

Conversation history, diagnostic information, audit records, or other data
associated with use of Agent O may be retained according to the retention,
compliance, auditing, and administrative policies applicable to the
organization's Microsoft 365 environment and any connected services.

Agent O does not independently define those organizational retention periods.

## 8. Accuracy and Human Review

Agent O provides AI-assisted technical analysis. Responses may be incomplete or
incorrect and should be reviewed before changes are applied to production
systems.

Users remain responsible for following their organization's change management,
security, privacy, and support procedures.

This statement may be updated when Agent O's features, connected data sources,
or applicable requirements change. The latest version will be published at
