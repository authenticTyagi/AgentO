**Effective date:** October 1, 2026
**Last updated:** October 1, 2026

## 1. Purpose

Agent O is an AI-assisted L3 diagnostic tool intended to support authorized
users investigating Microsoft Outlook, Exchange Online, Hybrid Exchange,
mail flow, authentication, connectivity, mailbox, calendar, delegation,
free/busy, and related messaging issues.

By using Agent O, you agree to these Terms of Use and to applicable
organizational policies.

## 2. Authorized Use

Agent O must be used only for legitimate technical support, troubleshooting,
diagnostic, educational, or administrative activities that the user is
authorized to perform.

Users must comply with their organization's security, privacy, acceptable-use,
change-management, and data-handling policies.

## 3. AI-Generated Technical Guidance

Agent O uses artificial intelligence to analyze supplied evidence and generate
technical recommendations.

Agent O's responses are advisory and may contain errors, omissions, outdated
information, or incorrect interpretations.

Users must independently review recommendations before applying changes to
production systems.

Agent O does not replace Microsoft Support, organizational support procedures,
or professional technical judgment.

## 4. Administrative and Configuration Changes

Commands, scripts, configuration changes, or other remediation steps suggested
by Agent O must be reviewed before execution.

Users are responsible for:

- Confirming they have authorization to perform the action
- Understanding the scope and impact of the change
- Following organizational change-control requirements
- Maintaining appropriate backups or rollback procedures
- Validating the result after the change

Do not execute a command solely because Agent O suggested it.

## 5. Prohibited Use

Users must not use Agent O to:

- Obtain or expose passwords, tokens, credentials, or other secrets
- Access systems, mailboxes, or information without authorization
- Circumvent security, authentication, authorization, or organizational controls
- Intentionally disclose unnecessary personal or confidential information
- Perform malicious, unlawful, abusive, or unauthorized activities
- Misrepresent AI-generated analysis as verified evidence

## 6. Diagnostic Data

Provide only the minimum diagnostic information required to investigate an
issue.

Where possible, redact unrelated personally identifiable information,
credentials, email addresses, identifiers, and confidential content before
submitting logs or diagnostic output.

Never submit passwords, authentication tokens, session cookies, API keys,
private keys, or similar secrets.

root cause will be identified.

Where sufficient evidence is unavailable, Agent O may provide a hypothesis,
request additional evidence, or recommend escalation.
