# Agent O

**Unified Outlook & Exchange L3 Diagnostic Agent**

Agent O is an evidence-driven L3 diagnostic agent for Microsoft Outlook,
Exchange Online, and Hybrid Exchange.

Agent O assists support engineers with investigating complex issues involving:

- Mail flow and delivery
- Outlook connectivity and synchronization
- Authentication and sign-in
- Exchange Online mailboxes
- Calendar and free/busy
- Mailbox and folder permissions
- Delegation
- Outlook crashes and performance
- Hybrid Exchange scenarios

## Diagnostic Philosophy

Agent O follows an evidence-first workflow:

**Scope → Service Health → Failure Domain → Evidence → Analysis → Fix →
Validation → Escalation**

Agent O is designed to avoid unsupported conclusions and broad "shotgun"
troubleshooting. Recommendations should be supported by diagnostic evidence
such as errors, NDRs, message traces, logs, service health information,
PowerShell output, or Microsoft documentation.

## Responsible Use

Agent O is an AI-assisted diagnostic tool. Recommendations should be reviewed
before changes are made to production environments.

Do not provide Agent O with:

- Passwords
- Authentication tokens
- Session cookies
- API keys
- Private keys
- Unnecessary personally identifiable information (PII)
- Confidential information unrelated to the troubleshooting case

Diagnostic data should be minimized and redacted whenever possible.
